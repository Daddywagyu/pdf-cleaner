# Local PDF Pen Remover

โปรแกรม Windows สำหรับ **ลบรอยปากกาสีแดงและสีน้ำเงินออกจาก PDF** ประมวลผลในเครื่องทั้งหมด (Offline)
ไม่มี Cloud / API Key / Telemetry และไม่เปิดไฟล์ด้วยโปรแกรมภายนอกอัตโนมัติ
หลักการสำคัญ: **รักษารายละเอียดต้นฉบับมาก่อนความสะอาดของสี** — ไม่ลบ "ทุกพิกเซลสีแดง/น้ำเงิน"
แต่ตรวจจับสีใน CIELAB แล้ววิเคราะห์รูปร่างเส้น (Connected Components, ความหนาเส้น, แถวตัวอักษรพิมพ์, รูปภาพ) ก่อนลบ

## 1. ติดตั้ง (Windows 10/11)

ต้องมี Python 3.12 (ติ๊ก *Add python.exe to PATH* ตอนติดตั้ง)

```bat
cd local_pdf_pen_remover
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 2. รันโปรแกรม

```bat
python main.py
```
หรือเปิดไฟล์ทันที: `python main.py samples\sample_scanned_pen.pdf` — ลากไฟล์ PDF มาวางในหน้าต่างได้เช่นกัน

## 3. ขั้นตอนใช้งาน

1. **Open PDF** (หรือลากไฟล์มาวาง) — ซ้ายคือ Thumbnail ทุกหน้า ถ้ามีรหัสผ่านจะถามรหัส
2. เลือก **Removal Mode** และปรับ Sensitivity / Mask Expansion / Inpainting Radius ที่แถบขวา
3. กด **Preview** → ระบบตรวจจับและแสดง **Mask สีเขียว = บริเวณที่จะถูกลบ** (ซ่อน/แสดงได้)
4. แก้ไขด้วยมือได้: 🖌 *เพิ่มพื้นที่ลบ*, 🧽 *คืนพื้นที่* (ที่ระบบตรวจผิด), Undo/Redo (Ctrl+Z / Ctrl+Y), Reset หน้า
5. กด **Process Current Page** หรือ **Process All Pages** (ทำงานใน Thread แยก ยกเลิกได้ด้วย *ยกเลิกงาน*)
6. เปรียบเทียบด้วยมุมมอง *ต้นฉบับ / ผลลัพธ์ / แบ่งหน้าจอ / สไลเดอร์ ก่อน-หลัง* (ล้อเมาส์ = ซูม, ปุ่มกลางลาก = เลื่อน)
7. **Export PDF** → เลือกโฟลเดอร์ → ได้ `ชื่อไฟล์_cleaned.pdf` (ไม่เขียนทับต้นฉบับ, ตรวจจำนวนหน้า/ขนาดหน้า/เปิดไฟล์ซ้ำหลังบันทึก)

### โหมดการลบ
| โหมด | พฤติกรรม |
|---|---|
| A Conservative | ลบเฉพาะเส้นที่มั่นใจมาก เส้นสั้น/สีอ่อนอาจไม่ถูกลบ — เหมาะเอกสารที่รายละเอียดสำคัญ |
| B Balanced (ค่าเริ่มต้น) | สี + รูปร่างเส้น + บริบท, เชื่อมเศษเส้นที่ขาด, ขยาย Mask ปรับได้, Inpainting |
| C Advanced | เหมือน B แต่ตรวจเส้นสีอ่อนได้มากขึ้น และใช้ *Transmittance Un-mixing* กับหมึกโปร่งแสง (ไฮไลต์) ทำให้ข้อความที่อยู่ใต้หมึกยังคงอยู่ มีจุดต่อยอดสำหรับโมเดล AI ในเครื่องที่ `core/restoration_engine.py` |

### วิธีฟื้นฟูภาพ
อัตโนมัติ (เลือกตามพื้นที่: พื้นกระดาษเรียบ → ประมาณพื้นหลัง + เม็ดเกรนให้เนียน / ใกล้ตัวอักษร-ภาพ → Inpaint), Telea, Navier-Stokes, ประมาณพื้นหลัง
เส้นตารางแนวนอน/แนวตั้งที่ถูกปากกาพาดผ่านจะถูกลากต่อให้อัตโนมัติ และมีรอบตรวจสีตกค้างหลังลบ

## 4. คำสั่งทดสอบ

## 6. แก้ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ปากกาสีอ่อนไม่ถูกตรวจจับ | เพิ่ม Sensitivity ของสีนั้น หรือใช้โหมด Advanced แล้วกด Preview ดู Mask |
| ลบตัวอักษร/โลโก้สีแดง-น้ำเงินที่เป็นส่วนของเอกสาร | ใช้โหมด Conservative หรือ 🧽 *คืนพื้นที่* วาดทับบริเวณนั้น |
| ยังมีขอบสีเหลือ | เพิ่ม Mask Expansion (2→4) หรือ Inpainting Radius |
| ปากกาทับตัวอักษร ตัวอักษรใต้เส้นหายหรือเบลอ | ข้อมูลที่ถูกหมึกทึบบังกู้คืนไม่ได้จริง โปรแกรมไม่สร้างตัวอักษรใหม่ (Advanced กู้ได้เฉพาะหมึกโปร่งแสง) |
| ปากกาทับรูปภาพสีฟ้า/แดงสด ตรวจไม่เจอ | ตั้งใจเพื่อไม่ทำลายภาพ → ใช้ 🖌 *เพิ่มพื้นที่ลบ* ระบายเอง |
| หน่วยความจำไม่พอ / ช้า | ลด DPI (200) — โปรแกรมลด DPI อัตโนมัติเมื่อหน้ากว้างเกิน 150 ล้านพิกเซล |
| ไฟล์ผลลัพธ์ค้นหา/คัดลอกข้อความไม่ได้ | หน้าที่ประมวลผลจะกลายเป็นภาพ ให้เปิด *คงข้อความที่ค้นหาได้*; หน้าที่ไม่ได้ประมวลผลคงข้อความเดิม 100% |
| ไฟล์ปลายทางมีแล้ว | โปรแกรมถามก่อนเขียนทับ (ไม่แตะไฟล์ต้นฉบับ) |
| Log ข้อผิดพลาด | `%LOCALAPPDATA%\LocalPDFPenRemover\app.log` (เก็บในเครื่องเท่านั้น) |

## 7. ผลทดสอบ (รันจริงบน Linux, Python 3.12, PyMuPDF 1.28, OpenCV 4.13, PySide6 6.12)

ข้อความพิมพ์สีแดง/สัญลักษณ์สี/รูปภาพต้องไม่ถูกลบ, หลายหน้า, PDF มีข้อความจริง+เวกเตอร์, หน้าหมุน 90°, 200/300/400 DPI,

### ข้อจำกัดที่ต้องทราบ (ตรงไปตรงมา)
- ทดสอบบน **Linux เท่านั้น** — ยังไม่ได้รัน GUI จริงบน Windows และยังไม่ได้สร้าง `.exe` (ต้องรัน `build_exe.bat` บนเครื่อง Windows)
- GUI ทดสอบแบบ offscreen (ไม่มีการดูด้วยตา เช่น ตำแหน่งปุ่ม/ความสวยงาม)
- ข้อมูลทดสอบเป็น **ภาพสังเคราะห์** ไม่ใช่เอกสารสแกนจริงจากผู้ใช้ — ควรลองกับเอกสารจริงแล้วปรับ Sensitivity
- Text layer ที่เก็บกลับเป็นแบบ Latin-1 เท่านั้น ข้อความ **ภาษาไทยบนหน้าที่ถูกประมวลผลจะไม่ถูกเก็บเป็น text ที่ค้นหาได้** (ระบบแจ้งเตือนตอน Export) หน้าที่ไม่ประมวลผลคงเดิมทุกอย่าง
- หน้าที่ประมวลผลจะเป็นภาพ: ลิงก์ถูกคัดลอก, Annotation/ฟอร์มของหน้านั้นไม่ถูกคงไว้; Bookmark/Metadata คงไว้ระดับเอกสาร
- ปากกาที่ทับ *พื้นที่สีแดง/น้ำเงินสดขนาดใหญ่* (รูปภาพ/กราฟิก) ไม่ตรวจจับอัตโนมัติ เพื่อป้องกันความเสียหาย
